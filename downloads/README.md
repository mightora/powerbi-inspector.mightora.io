Mightora Power BI Report Inspector – Offline Edition
Offline Edition – No Internet Connection Required

Open power-bi-inspector-offline.html directly by double-clicking. No installation or server needed. Local data stays in the browser. To inspect requests: F12 → Network → Preserve log, reload. The Network Transparency readout has limitations and is not an audit.

Supports PBIP/PBIR/TMDL and BIM metadata. PBIX files aren't supported. No Power BI connection, analytics or telemetry.
