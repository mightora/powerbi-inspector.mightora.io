    GETTING STARTED

    Three steps. No infrastructure.

    01

    Save as a Power BI project

    In Power BI Desktop, save your report as a .pbip project. Use the enhanced report (PBIR) format for the richest report-level detail.

    02

    Load the project files

    Select the entire project folder or ZIP it and select the archive. Include the .Report and .SemanticModel folders if you have both.

    03

    Explore and export

    Search the metadata explorer, inspect original file paths and create documentation in your preferred format.

    PRIVACY & TRUST

    Understand what the browser is doing

    Report source files are handled locally via browser File APIs. The app does not upload project contents, execute DAX or M queries, or connect to Power BI services. Your online browser may still request Mightora’s shared UI, the brand logo and other page resources.

    Network transparency

    The resources below are visible to the browser’s Resource Timing API. This is not a complete network/security monitor.

    Verify it yourself with developer tools

    1. Press F12 or use the browser menu to open Developer Tools.
    2. Open the Network tab and enable Preserve log.
    3. Reload the application; inspect requests, destinations and payloads.
    4. Use the offline HTML and repeat: app-related requests should be absent.

    Resource Timing may omit some requests, including those made by extensions or blocked by privacy settings. F12 may not be available on mobile browsers.

    FAQ

    Frequently asked questions

    Can I upload a .pbix file directly?

    Not currently. PBIX is a packaged binary format and is not parsed by this tool. Save as a Power BI Project (.pbip) and select its entire folder, or create a ZIP of the project. A single .pbip file is only a pointer to the project folders.

    Will every measure, relationship and filter be documented?

    Only what can be extracted from the supplied metadata. Semantic model measures and relationships usually require TMDL or model.bim; report details require PBIR or legacy report.json. Some dynamic, binary, encrypted, connected-model or visual-specific properties may be unavailable. This is an inventory, not a full Power BI model validation engine.

    Does it send project data anywhere?

    No. File reading, metadata parsing and document creation occur entirely in your browser. The online edition loads Mightora shared UI and branding assets; the downloadable offline edition embeds its own assets and blocks network connections with a restrictive Content Security Policy.

    Can the tool edit or deploy a Power BI project?

    No. This version is a read-only documentation and troubleshooting aid. It does not modify report definitions or deploy to Microsoft Fabric.

    Which format should I use in Azure DevOps or GitHub?

    Markdown suits repository documentation, JSON suits automation, CSV suits inventories, Word suits stakeholder handover, and HTML is a portable read-only report for sharing.
